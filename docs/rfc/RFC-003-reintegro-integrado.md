# RFC-003 — Reintegro integrado

- Estado: futuro; fuera de alcance de v1

Analizar una devolución ejecutada y verificada mediante Mercado Pago: permisos, idempotencia, estados pendiente/fallido, restitución de stock y documentos fiscales. En v1, el reintegro de un pedido pagado se declara manualmente y no invoca Mercado Pago.
